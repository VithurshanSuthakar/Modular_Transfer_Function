07 · LECTURE II · EVENT CAMERAS

Events represent brightness changes

Move a contrast edge across a sensor. The event threshold controls the number of ON and OFF events generated by the moving brightness transition.

Illustrative event raster

Teal = ON (brighter), red = OFF (darker). A deterministic edge demonstration, not an EVK4 hardware noise or refractory-time simulation.
